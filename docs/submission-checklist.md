## 5. 최종 제출 전 판정

1~7단계와 8단계의 설정·인증·재현·로컬 커밋을 확인했다. 사진과 마스킹 파일도 로컬에 준비됐다. 최종 문서 수정·main 푸시·GitHub 웹 확인 뒤 전체 완료로 표시한다.

완성도를 높이려면 명령을 나열하는 데서 끝내지 않고, 무엇을 확인했고 어떤 출력으로 성공을 판단했는지 설명한다. 미실행 항목을 완료로 표시하거나 예시 출력을 실제 결과처럼 제출하지 않는다.
