브라우저 스크린샷 추가 방법

대화에서 제공한 화면에는 localhost:8080 주소창과 My Docker Web Server 페이지가 함께 보였습니다.
접속 증거로 사용할 수 있으나 현재 압축본에는 원본 PNG 파일이 포함되지 않았습니다.

1. Windows에 저장한 접속 화면 파일을 05-web-access.png로 준비합니다.
2. 이 안내 파일과 같은 docs/images 폴더에 넣습니다.
3. docs/05-custom-image.md의 9절에 다음 한 줄을 추가합니다.

![주소창이 포함된 맞춤 웹 페이지 접속 화면](images/05-web-access.png)

4. 같은 문서 마지막의 PNG 추가 체크박스를 완료로 수정합니다.
5. GitHub에 업로드한 뒤 이미지가 표시되는지 확인합니다.

이미지의 확장자가 실제 PNG인지 확인하세요. JPG 파일을 이름만 PNG로 바꾸는 방식은 사용하지 않습니다.
원본을 PNG 파일로 다시 첨부하면 이후 묶음에 직접 포함할 수 있습니다.
이 파일은 이미지 자체가 아니라 파일 배치 방법을 설명하는 안내문입니다.

6단계 수정 전후 화면도 같은 방식으로 추가합니다.

파일 위치:
docs/images/06-bind-before.png
docs/images/06-bind-after.png

docs/06-port-bind-mount.md에 추가할 Markdown:

![수정 전: localhost:8081의 원래 웹 페이지](images/06-bind-before.png)
![수정 후: 같은 주소에 변경된 제목과 문구](images/06-bind-after.png)

두 화면은 대화에서 주소와 내용이 확인됐지만 현재 압축본에 원본 PNG가 포함된 것은 아닙니다.
파일을 넣은 뒤 실제 이미지가 표시되는지 확인하고 해당 체크박스를 완료로 수정하세요.
