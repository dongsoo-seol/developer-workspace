확인한 결과
1~7단계 실습 및 8단계 설정·인증·재현 검증 완료
실습 자료 커밋: 1edb655

main 푸시 성공: f89744e..de8e0e5 main -> main
GitHub에서 파일과 사진 표시 확인
저장소 화면: docs/images/08-github-repository.png로 PC 저장 확인

마무리 순서
1. 안내된 문서 경로만 전달용 브랜치에서 적용한다.
2. 저장소 화면과 최종 확인 문서를 추가 커밋·푸시한다.
3. GitHub README에서 저장소 화면까지 보이는지 확인한다.
4. 과제 제출 규칙에 맞는 공개 또는 평가자 접근 권한을 확인한다.
5. 과제 제출처에 위 저장소 링크를 제출한다.

전달용 브랜치에서 docs 전체를 복원하지 않는다.
사용자 PC의 사진 원본을 유지하고, 지정된 문서 파일만 적용한다.
GitHub 업로드와 과제 제출처의 링크 등록은 별개이다.
